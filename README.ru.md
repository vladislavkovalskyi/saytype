## Зачем

- **Текст виден, пока говоришь.** Слова появляются в острове у выреза прямо во время речи.
- **Русский и английский в одной фразе.** Скажи «поправь useEffect в Header» и получишь `useEffect` так, как он пишется в коде, а не «юз эффект».
- **Текст сразу оформлен.** Знаки препинания, абзацы по паузам, нумерованный список, когда перечисляешь. Маленькая локальная модель расставляет структуру в длинных диктовках и не меняет слова.
- **Или как пишешь в чате.** Режим «Как в чате» пишет строчными и ставит только запятые. Фильтры убирают слова, которые ты не хочешь видеть.
- **Режим под каждое приложение.** Как в чате в Telegram, код голосом и обратные кавычки в Claude Code и Cursor, сообщение коммита по кнопке.
- **Локальное переписывание ИИ.** Преврати поток мыслей в чистый промпт, коммит или английский текст через Qwen3 4B, Ollama или LM Studio.
- **650+ терминов разработчика сразу.** Claude Code, ChatGPT, Next.js, Supabase, Figma, LGTM и другие пишутся правильно без настройки.
- **Офлайн.** Распознавание и оформление идут на Neural Engine и GPU. Сеть нужна только для загрузки моделей.

Сделано для тех, кто весь день говорит с агентами: Claude Code, Cursor, Codex, терминал, браузер, мессенджеры.

## Установка

Проще всего через Homebrew:

```sh
brew install --cask vladislavkovalskyi/tap/saytype
```

Или [скачай saytype.dmg](https://github.com/vladislavkovalskyi/saytype/releases/latest/download/saytype.dmg) и перетащи saytype в «Программы».

> [!NOTE]
> saytype бесплатный и не нотаризован Apple: нотаризация стоит $99 в год. После установки из DMG macOS может не открыть приложение с первого раза: открой **Системные настройки → Конфиденциальность и безопасность** и нажми **Всё равно открыть**, или выполни
> `xattr -dr com.apple.quarantine /Applications/saytype.app`. Homebrew делает это сам.

## Языки

Whisper распознаёт 99 языков. Свой выбери в **Текст → Язык речи**, в меню в строке меню или на острове.

| Язык | Статус |
|---|---|
| Русский, английский | проверены в ежедневной работе; слова-паразиты, списки и термины из кода настроены под них |
| Польский, испанский, немецкий, украинский и ещё 90+ | Whisper их распознаёт, скорее всего всё заработает; оформление базовое |
| Авто | Whisper сам определяет язык каждой диктовки |

Говоришь по-русски с английскими терминами? Выбери русский: встроенный словарь превратит «юз эффект» в `useEffect`. Попробовал другой язык? Расскажи, как прошло, в [Issues](https://github.com/vladislavkovalskyi/saytype/issues).

## Стиль и фильтры

| | Как сказал | Что получишь |
|---|---|---|
| Обычно | привет я закончил юз эффект в реакте завтра покажу апи ок | Привет. Я закончил useEffect в React, завтра покажу API. Ок? |
| Как в чате | то же самое | привет я закончил useEffect в React, завтра покажу API ок |

- **Как в чате.** Один переключатель: строчные буквы и только запятые, как пишут в мессенджерах. `API`, `useEffect` и `GitHub` сохраняют регистр.
- **Пунктуация.** Полная с абзацами и списками, только запятые или без знаков. Регистр: как в предложении или всё строчными.
- **Фильтры слов.** Добавь слова и фразы, которые нужно убирать из каждой диктовки. Мат можно скрывать до первой буквы: б****.
- **Встроенный словарь.** 650+ терминов из ИИ, фронтенда, бэкенда, дизайна, DevOps и сленга разработчиков: Claude Code, ChatGPT, Next.js, Supabase, Figma, LGTM. Его можно выключить или добавить свои слова в **Словаре**.

## Режимы

saytype выбирает режим по приложению, в которое ты диктуешь. У каждого режима своя пунктуация, регистр, правила для кода, языковая модель и вывод. Переключить вручную: <kbd>⌃</kbd><kbd>⌥</kbd><kbd>M</kbd>, меню в строке меню или остров.

| Режим | Включается в | Что меняется |
|---|---|---|
| Обычный | остальных приложениях | правила из раздела **Текст** |
| Сообщение | Telegram, WhatsApp, Сообщения, Discord, Viber | как в чате: строчные, только запятые |
| Промпт для агента | Терминал, iTerm, Ghostty, Warp, Cursor, VS Code, Zed, Claude, ChatGPT | код голосом и `обратные кавычки` |
| Коммит | выбирается вручную | Conventional Commit на английском |
| Письмо | Почта, Spark, Outlook | полная пунктуация, без слов-паразитов |

Можно создать свой режим с инструкцией, например «оформи как баг-репорт с шагами воспроизведения».

## Код голосом

В режимах «Промпт для агента» и «Коммит», а также в любом режиме, где ты это включишь:

| Говоришь | Получаешь |
|---|---|
| кэмел кейс юзер дата | `userData` |
| константа макс ретрай каунт | `MAX_RETRY_COUNT` |
| src слэш компонентс слэш хедер точка tsx | `src/components/header.tsx` |
| response точка status строго равно 200 | `response.status === 200` |
| vlad собака gmail точка com | `vlad@gmail.com` |

«Поправь кэмел кейс юзер дата в src слэш app точка tsx» превращается в «Поправь `userData` в `src/app.tsx`.». Обычная речь не меняется: «моя собака», «точка зрения».

Добавь папку с кодом в **Словарь → Проекты**: saytype прочитает оттуда имена функций, компонентов и файлов и подскажет их Whisper, так что `useUserData` запишется так же, как в твоём коде.

## Языковая модель

Необязательное переписывание работает на твоём Mac: Qwen3 4B (2,3 ГБ, saytype скачает сам), или твои [Ollama](https://ollama.com) и [LM Studio](https://lmstudio.ai).

- **Промпт для агента:** поток мыслей превращается в цель, контекст и шаги.
- **Коммит:** сообщение Conventional Commit на английском.
- **Чище:** убирает повторы и оговорки: «не X, а Y» → Y.
- **Своя инструкция:** что угодно.
- **Перевод на английский** с любого языка, термины остаются на месте.

saytype проверяет каждый ответ модели: если пропало имя файла, идентификатор, число или ссылка, вставляется текст как ты его сказал. На M3 Pro Qwen3 4B отвечает примерно за 1 с на короткую фразу и за 3–8 с на 150 слов; <kbd>esc</kbd> вставляет текст, не дожидаясь модели.

## Голосовые команды

| Говоришь | Что происходит |
|---|---|
| новая строка · new line | перенос строки |
| новый абзац · new paragraph | новый абзац |
| удали последнее предложение · delete last sentence | удаляет предложение перед командой |
| открой кавычки … закрой кавычки | «…» |
| отправь · send it, в самом конце | нажимает Enter после вставки |

Команды срабатывают только отдельной фразой, поэтому «добавь новую строку в таблицу» и «отправь письмо Васе» остаются текстом.

## Модели

| Модель | Размер | Что делает |
|---|---|---|
| Whisper large-v3-turbo через [WhisperKit](https://github.com/argmaxinc/WhisperKit) | 632 МБ | речь в текст на Neural Engine, живой и финальный проход |
| Qwen3 1.7B 4-bit через [MLX](https://github.com/ml-explore/mlx-swift-lm) | 944 МБ, по желанию | размечает предложения как абзацы или пункты списка; текст собирается из меток, слова не меняются |
| Qwen3 4B Instruct 2507, 4-bit через MLX | 2,3 ГБ, по желанию | переписывание и перевод в режимах с языковой моделью; вместо неё подойдут Ollama или LM Studio |

Модели лежат в `~/Library/Application Support/dev.kovalskyi.saytype/Models` и скачиваются с Hugging Face при первом запуске.

На M3 Pro фраза в 5 секунд готова примерно через 1,2 с после отпускания клавиши. Умная структура добавляет ~0,6 с к длинным диктовкам и пропускается для коротких.

## Приватность

- Звук обрабатывается в памяти и не пишется на диск.
- История диктовок — локальный JSON-файл, её можно очистить или ограничить срок хранения.
- Ни аккаунтов, ни аналитики. Сеть нужна только для загрузки моделей и проверки обновлений.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Микрофон | слушать, пока зажата клавиша записи |
| Мониторинг ввода | замечать клавишу записи в любом приложении |
| Универсальный доступ | вставлять текст в активное поле |

saytype вставляет через буфер обмена и возвращает прежнее содержимое. В поля паролей не вставляет.

## Как всё сбросить

**Пройти настройку заново.** Нажми иконку saytype в строке меню → **Пройти настройку заново…** История, словарь и модели останутся.

**Сбросить разрешения**, например если после обновления перестала работать вставка:

```sh
tccutil reset Accessibility dev.kovalskyi.saytype
tccutil reset ListenEvent dev.kovalskyi.saytype   # мониторинг ввода
tccutil reset Microphone dev.kovalskyi.saytype
```

Потом открой saytype и выдай разрешения снова.

**Начать с нуля.** Закрой saytype через строку меню и выполни:

```sh
tccutil reset All dev.kovalskyi.saytype                           # разрешения
defaults delete dev.kovalskyi.saytype                             # настройки и словарь
rm -rf ~/Library/Application\ Support/dev.kovalskyi.saytype       # история и модели, до 1,6 ГБ
rm -rf ~/Library/Caches/dev.kovalskyi.saytype
```

Следующий запуск начнёт настройку с первого шага и скачает Whisper заново. Чтобы оставить модели, пропусти строку `rm -rf …Application Support…` и удали внутри только `history.json`.

**Удалить saytype.**

```sh
brew uninstall --zap --cask saytype
```

Без Homebrew: закрой saytype, перенеси его из «Программ» в Корзину и выполни команды из «Начать с нуля». Если включал запуск при входе, убери saytype в Системные настройки → Основные → Объекты входа.

## Вопросы

**Текст не вставляется.** Проверь saytype в «Универсальном доступе». Если включено, а вставка не работает, сбрось разрешения, как описано выше.

**fn открывает эмодзи.** Системные настройки → Клавиатура → «Нажатие клавиши 🌐» → «Ничего не делать», или выбери правый ⌥ клавишей записи.

**Первый запуск долгий.** Core ML один раз готовит Whisper под твой чип, это 2–3 минуты. Дальше запуск занимает секунды.

**Перевод не работает.** Whisper turbo не умеет переводить, поэтому для перевода нужна языковая модель: включи Qwen3 4B, Ollama или LM Studio в разделе **Модель**.

**Работает ли мой язык?** Скорее всего да. Whisper знает 99 языков, saytype проверен на русском и английском. Выбери свой язык в Текст → Язык речи, а не «Авто»: короткие фразы распознаются лучше, когда язык известен.

**Остров не открывается при наведении.** Панели при наведении нужен экран MacBook с вырезом. На других мониторах остров появляется во время диктовки, а большая часть тех же настроек есть в меню в строке меню.

## Сборка из исходников

Нужны Xcode 26+, [XcodeGen](https://github.com/yonaskolb/XcodeGen) и компонент Metal Toolchain.

```sh
brew install xcodegen
xcodebuild -downloadComponent MetalToolchain
xcodegen generate
```
