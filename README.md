# voicemode

Голосовая диктовка для macOS, сделанная под вайб-кодинг. Зажимаешь Fn, говоришь по-русски
вперемешку с английскими терминами, видишь текст в стеклянной плашке прямо во время речи,
отпускаешь — и в активное приложение вставляется уже оформленный текст: с запятыми, абзацами и
списками. Редактор, терминал с Claude Code, адресная строка, Telegram — куда угодно.

Всё работает на самом Mac: без интернета, без подписок, без облачных API.

## Статус

Техдизайн: [`docs/dev/001-voicemode-mvp/`](docs/dev/001-voicemode-mvp/). Кода пока нет.

## Требования

- macOS 26 и новее, Apple Silicon.
- Для сборки: Xcode 26+, XcodeGen, компонент Metal Toolchain.
