# 004 · Автоперевод из плашки — Proposal

**Review:** ждёт владельца. Отклонения при реализации — в [`implementation.md`](implementation.md).

## Коротко

Две новые настройки — включён ли автоперевод и на какой язык, — один новый элемент в плашке и
сквозная поддержка языка перевода в запросе к модели. Перевод идёт тем же путём, что и перевод
режима: локальная модель переписывает готовый текст, валидатор проверяет результат, дальше
обычная доставка.

## Настройки

```swift
/// Everything spoken is translated, whatever mode the dictation runs in.
public var autoTranslate = false
/// Where autoTranslate translates to; kept while the switch is off, so it comes back as it was.
public var translateTarget = SpeechLanguage.english
```

Два поля, а не одно необязательное: выключенный тумблер должен помнить язык. `SpeechLanguage`
уже есть, в нём все 99 языков Whisper и локализованные названия.

Приоритет: **общий перевод сильнее режима**. Включён — переводится всё, даже в режимах без
перевода. Выключен — решает режим (`translateToEnglish`), как сейчас.

## Элемент в плашке

Чип из двух половин под одной капсулой, рядом с «Structure»:

```
┌──────────────┐   выключен: тумблер серый, код языка приглушён
│ (o—)  EN ⌄   │   включён:  тумблер янтарный
└──────────────┘
   ↑      ↑
   тумблер  меню языков
```

- Левая половина — тумблер, как у «Structure»: один клик включает и выключает.
- Правая — код языка (`EN`, `RU`, `PL`) и шеврон; клик открывает меню: русский, английский, затем
  остальные языки по алфавиту, как в меню строки состояния.
- В острове чип встаёт в нижний ряд панели: `[RU EN Auto] [Mode] [Structure] [Translate] [Mic]`.
  Ряд перестаёт помещаться в 504 pt, поэтому панель расширяется до 560 pt — предел острова
  572 pt, так что это в габарите.
- В пилюле чип встаёт в строку наведения после чипа режима; пилюля считает свою ширину сама.
- В меню строки состояния появляется подменю **Translate**: «Off», затем языки — так же, как
  устроено подменю «Language».

Раздел настроек не трогаем: перевод — вещь, которую включают на минуту и выключают, ей место
там, куда тянется рука во время работы. В Modes перевод для одного режима остаётся как был.

## Что меняется в конвейере

`RewriteRequest` умеет только «перевести на английский» (`translate: Bool`). Добавляется цель:

```swift
/// English name of the language to translate into, e.g. "Ukrainian"; nil means English.
public var targetLanguage: String?
```

- `answersInEnglish` — `translate`, когда цель английский или не задана, плюс стиль `.commit`.
- `languageRule` — «Write the answer in \(target).»
- `taskReminder` — «Translate this dictation into \(target).»
- `RewriteValidator.languageMatches` для нелатинской цели ничего не проверяет: проверка «ответ в
  том же алфавите, что диктовка» для перевода на украинский или польский ложна. Английский
  по-прежнему проверяется, там она работает.

В `DictationController.finalize` цель считается один раз:

```swift
let target = value.autoTranslate ? value.translateTarget : (mode.translateToEnglish ? .english : nil)
```

и дальше по существующим веткам: `whisperTranslates` остаётся только для английского и только для
моделей, которые это умеют; во всех остальных случаях переводит языковая модель.

## Когда перевести нечем

Whisper переводит только на английский и только на large-v3; модель по умолчанию — turbo. Поэтому
включение перевода при выключенной языковой модели ничего бы не дало.

Решение: тумблер включается (это выбор человека), но плашка сразу показывает «Language model is
off» — уведомление уже есть, оно же используется для правки выделенного. Дальше, пока модель не
появится, диктовки идут без перевода, как и любая другая работа модели в этом приложении.

## Риски

| Риск | Что делаем |
|---|---|
| Человек включил перевод и не заметил, что он включён | Тумблер янтарный, как «Structure»; язык виден кодом рядом |
| Перевод молча не работает без модели | Уведомление в момент включения |
| Ряд чипов не помещается | Панель острова 560 pt, чип компактный: тумблер, две буквы, шеврон |
| Модель переводит и теряет термины | Тот же валидатор, что у остальных переписываний: код, пути, числа и ссылки обязаны остаться |
