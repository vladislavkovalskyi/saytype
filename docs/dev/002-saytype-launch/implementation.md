## Запрос

- Пилюля и меню в строке меню выглядели «вайб-кодно».
- Остров показывал «вставлено» мелким текстом.
- Нужны интерактивный остров по наведению, популярный репозиторий и простая установка для любого
  владельца Mac.
- Имя voicemode занято проектом mbailey/voicemode, поэтому проект переименован в saytype.

## Что сделано

**Остров** (`App/Sources/Overlay`)
- Курсор на вырезе: остров «подпрыгивает», через 0,3 с открывается панель 444 × 180 pt.
- В панели кнопка записи, последняя диктовка с «Скопировать» и «Вставить ещё раз», язык,
  «Структура», микрофон, «История» и настройки.
- Закрывается через 0,35 с после ухода курсора, но не пока открыто меню из панели.
- Панель больше, чем остров. Клики проходят сквозь неё везде, кроме видимой формы:
  `OverlayController` следит за курсором глобальным монитором `mouseMoved`, а пока курсор над
  панелью, опрашивает положение 30 раз в секунду.
- Итог вставки: иконка целевого приложения и галочка в «ушах» выреза.
- Уведомления типизированы (`DictationController.Notice`) и занимают одну строку.
- Живой текст: слова по одному, новые проявляются из размытия. Высота острова — одна или две
  строки по ширине текста.

**Пилюля.** В покое полоска 56 × 8 над Dock. При записи рамка и тень светятся в такт голосу, живой
текст растёт вверх отдельным пузырём.

**Меню.** `NSStatusItem` с нативным `NSMenu`, который пересобирается при каждом открытии.
- В шапке иконка приложения, имя и состояние модели.
- Последняя диктовка, «Недавние», язык, плашка, умная структура, «Проверить обновления…».
- ⌃⌥V и ⌃⌥C работают глобально через Carbon hot keys (`VMSystem/GlobalHotKeys`).

**Микрофон.** `VMAudio/AudioDevices` перечисляет входы Core Audio. `AudioCapture` ставит
выбранное устройство на input unit движка, UID хранится в `AppSettings.microphoneUID`.

**Локализация.** Исходный язык английский, `Localizable.xcstrings` на 223 ключа с полным русским
переводом, плюралы через каталог. Язык речи по умолчанию берётся из системного.

**Релизы.**
- `scripts/release.sh` сам выбирает режим: Developer ID с нотаризацией или Apple Development без
  неё.
- Дальше: DMG с фоном из `packaging/dmg`, appcast Sparkle 2, cask для личного tap.
- CI: `.github/workflows/ci.yml` (тесты и сборка), `release.yml` (по тегу `v*`).
- Подробности в [`docs/RELEASING.md`](../../RELEASING.md).

**Переименование.**
- Bundle id `dev.kovalskyi.saytype`, пакет `SaytypeKit`.
- `LegacyMigration` при первом запуске переносит папку поддержки и настройки из
  `dev.kovalskyi.voicemode`.
- Разрешения macOS привязаны к bundle id, поэтому их придётся выдать заново, а Core ML заново
  готовит Whisper под чип (~2,5 мин).

**README.** Английский и русский. Картинки собираются из настоящих рендеров интерфейса скриптом
`design/media/readme_media.py`, превью для соцсетей — `docs/media/social.png`.

## Приватность разработки

Проверочные запуски `--show-*`, `--demo-*` и `--snapshot-*`:
- не читают настройки и историю пользователя;
- показывают выдуманные диктовки, модели в состоянии «готово» и временный файл истории;
- не берут клавишу записи и не переносят данные.

`--snapshot-overlays <папка>` рисует все состояния острова и пилюли в PNG без окон на экране.

Правило появилось после того, как в первых проверочных запусках на экране и в скриншотах
агента оказалась настоящая история диктовок. Скриншоты удалены.

## Проверено

- Сборка без предупреждений в `App/Sources`, 52 теста пакета.
- Все состояния острова и пилюли — по рендерам `--snapshot-overlays`.
- Главное окно — на выдуманных данных.
- `scripts/release.sh` в режиме без нотаризации:
  - `saytype-0.1.0.dmg`, 11 МБ;
  - `codesign --verify --deep --strict` проходит;
  - в бандле `en.lproj` и `ru.lproj`;
  - appcast подписан ключом EdDSA.

## Не проверено

- Наведение, клики и меню из панели на реальном экране при запущенном приложении.
- Глобальные ⌃⌥V и ⌃⌥C.
- Смена микрофона на лету.
- Режим с Developer ID и нотаризацией, оба workflow на GitHub.
- Установка на чистом Mac с включённым Gatekeeper.
