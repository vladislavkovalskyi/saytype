# docs/dev — рабочие документы задач

Папка на задачу: `NNN-feature-name/`, где `NNN` — следующий свободный номер. Внутри по файлу на
стадию, в порядке чтения:

| Файл | Стадия | Что внутри |
|---|---|---|
| `request.md` | 1 · Request | что нужно и зачем, без реализации |
| `proposal.md` | 2 · Proposal | как решаем, границы, компромиссы |
| `plan.md` | 3 · Plan | этапы реализации и как каждый проверяется |
| `implementation.md` | 4 · Implementation | что в итоге вышло и что проверено живьём |
| `research.md` | по необходимости | что изучили, с источниками |

Каждый файл стадии несёт строку `Review:` — кто согласовал и когда.
