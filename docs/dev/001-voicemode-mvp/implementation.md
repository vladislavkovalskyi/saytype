# 001 · voicemode MVP — Implementation

Что получилось на деле, замеры и где реализация разошлась с [`proposal.md`](proposal.md).
Замеры на MacBook Pro M3 Pro, macOS 26.

## Модули

| Модуль | Что внутри |
|---|---|
| `VMCore` | настройки, словарь и `TermCanonicalizer`, `LiveAgreement`, фильтр галлюцинаций, жест клавиши записи, форматирование текста, `SmartStructure` и валидатор, история со статистикой |
| `VMAudio` | захват микрофона в 16 кГц моно, уровень для волны, чтение файлов для замеров |
| `VMTranscription` | `WhisperKitEngine`, `ModelStore` |
| `VMSystem` | разрешения, event tap клавиши записи, вставка через буфер, проверка поля пароля |
| `VMSmart` | загрузка Qwen3-1.7B с Hugging Face, разметка предложений через MLX |
| `vm-bench` | распознавание файлов с таймингами, `swift run vm-bench` |
| `vm-smart` | разметка текстов из файла; собирается только `xcodebuild`, MLX нужны шейдеры Metal |

Всё, что не требует UI и железа, покрыто тестами Swift Testing: `swift test` в
`Packages/VoicemodeKit`.

## Распознавание

Фразы — синтетический голос Milena из `Bench/make-synthetic.sh`, 4–7 секунд. Голос произносит
английские термины хуже человека, поэтому точность терминов на нём занижена. Время — финальный
проход после загрузки модели.

| Вариант | Prompt | Время на фразу |
|---|---|---|
| `turbo_632MB` | нет | ~0,7 с |
| `turbo_632MB` | только термины | ~1,2 с |
| `turbo_632MB` | пример текста и термины | ~1,6 с |
| `626MB` | только термины | ~2,05 с |

**Решение.** По умолчанию `turbo_632MB`. Живые проходы — без prompt и без таймкодов слов.
Финальный — с терминами и таймкодами, они нужны для абзацев.

**Первая загрузка модели** — 75–160 с: Core ML готовит модель под чип. В приложении первый
запуск занял ~150 с, второй — 5 с. Кеш подготовки у приложения свой, отдельный от `vm-bench`.
Если закрыть приложение раньше, подготовка начнётся заново. У `DictationController` на это время
состояние `loading`, в онбординге и разделе «Модель» — «Подготовка под M3 Pro».

**Токенизатор** WhisperKit по умолчанию качает при каждой загрузке. `ModelStore.download`
кладёт его в папку моделей, и после этого приложение не ходит в сеть.

## Умная структура

Семь продиктованных сообщений агенту: задачи, проблемы, требования, рассуждение. Разметка
правильная, если список там, где человек перечисляет, и его нет в связном рассказе.

**Подход «перепиши текст со структурой»**, промпт с правилами:

| Модель | Размер | Время | Результат |
|---|---|---|---|
| Qwen3.5-0.8B-4bit | 652 МБ | 0,3–0,6 с | переписывает слова, выдумывает содержание |
| Qwen3-1.7B-4bit | 984 МБ | ~1,1 с | почти всё возвращает как есть, один раз выдумал ответ |
| Qwen3.5-2B-4bit | 1,7 ГБ | ~1,2 с | один список из пяти, теряет слова |

**Подход «размечай предложения»**: модель получает `[1] … [2] …` и отвечает строками `1 T`,
`2 L`. Текст собирается из меток в `SmartStructure.render`.

| Модель | Время | Ошибки |
|---|---|---|
| Qwen3.5-0.8B-4bit | ~0,3 с | из пяти сообщений два размечены неверно: требования к эндпоинту стали списком, ревью PR — пятью абзацами |
| Qwen3-1.7B-4bit | ~0,55 с | из семи одно спорное: два последних условия эндпоинта стали списком |
| Qwen3.5-2B-4bit | ~0,55 с | из семи одно неверное: в ревью PR первый пункт ушёл во вводную фразу, а вывод стал пунктом |

**Решение.** Qwen3-1.7B-4bit и разметка: точность как у 2B при вдвое меньшем размере. В Swift
через MLX — 0,6 с на сообщение в Debug-сборке, загрузка с прогревом 3,4 с. Одиночная метка
«пункт» без соседей превращается в обычное предложение: так в `render` не бывает списка из
одного пункта.

**Apple Foundation Models** доступны на этом Mac, но `supportsLocale(ru_RU)` — `false`.

## Отклонения от proposal

- **RUPunct не подключали.** Whisper со списком терминов ставит знаки сам. Решим по записям
  владельца.
- **Системный движок `DictationTranscriber` не подключали.** Онбординг ждёт загрузки Whisper.
  Настройка `systemEngineFallback` есть в модели, но в интерфейсе её нет.
- **История — JSON-файл, а не SwiftData.** Записей мало, запросов нет, файл проще читать и
  чистить.
- **Длинные фразы.** Финальный проход всегда распознаёт весь звук; для записей длиннее 30 с
  WhisperKit режет по тишине (`chunkingStrategy: .vad`). Живой текст после 30 с не обновляется.
- **Переназначение клавиши** — Fn, правый ⌥ и правый ⌘. Произвольные сочетания через
  `KeyboardShortcuts` отложены.
- **«Вставить последнее» по горячей клавише** не сделано. Повторная вставка есть в меню и в
  истории: перед вставкой voicemode возвращает фокус приложению.
- **Шрифты и дизайн-язык** изменились после первых макетов: Onest и JetBrains Mono, цветовые миры,
  объёмные объекты из Blender. Proposal обновлён.

## Что не проверено

- Сквозная диктовка на реальном голосе: нужны разрешения Input Monitoring, Accessibility и
  Microphone для подписанной сборки. Проверены по отдельности: распознавание файлов, форматирование,
  плашка в обоих стилях на реальном экране.
- Матрица вставки по приложениям из плана (этап 5).
- Точность терминов на голосе владельца: фразы для записи — в `Bench/phrases.txt`.
